UltraPads

打击垫演奏与音乐创作。Flutter 界面 + Rust 实时音频引擎。

最新版本 — · 更新记录

Linux x86_64 · arm64

在终端运行（不需要 sudo；再次运行即更新）：

curl -fsSL https://ultrapads.plutokeating.beer/install | bash
选项与卸载 
curl -fsSL https://ultrapads.plutokeating.beer/install | bash -s -- --version 0.1.0
curl -fsSL https://ultrapads.plutokeating.beer/install | bash -s -- --prefix ~/apps/ultrapads
curl -fsSL https://ultrapads.plutokeating.beer/install | bash -s -- --no-desktop --no-modify-path
curl -fsSL https://ultrapads.plutokeating.beer/install | bash -s -- --uninstall

安装到 ~/.local/opt/ultrapads，命令为 ~/.local/bin/ultrapads。卸载会保留曲库与设置。需要 GTK 3 与 ALSA（PipeWire / PulseAudio 兼容层即可），缺失时脚本会询问是否安装。

Android 8.0+

大多数手机选 arm64-v8a。安装后应用内会提示新版本。

arm64-v8a armeabi-v7a x86_64

从 0.0.1 升级：0.1.0 起改用正式签名，请先卸载旧版再安装（曲库会清空，可先用 Hub 同步到电脑）。
